# Sicherheit

## Sicherheitslücke melden

Bitte melde Sicherheitsprobleme **nicht** als öffentliches Issue, sondern privat über
**Security → Report a vulnerability** in diesem Repository.

Hilfreich sind:

- eine kurze Beschreibung des Problems und der möglichen Auswirkungen
- Schritte, um es nachzustellen
- die betroffene Version (siehe Eigenschaften der exe → Details)

## Unterstützte Versionen

Sicherheitskorrekturen gibt es jeweils für die neueste Version unter Releases.
